# Presets

`apple.json`, `big_leaf_maple_medium.json`, `big_leaf_maple_large.json`, `flowering_dogwood.json`, `spring_pussy_willow.json`, `winter_thicket.json` and `cedar.json` are original to ze_tree.
`oak_small.json`, `oak_medium.json` and `oak_large.json` started from ez-tree's oak presets and have since been reworked for ze_tree.
The other tree presets are copied unchanged from
[ez-tree](https://github.com/dgreenheck/ez-tree), commit
`dcf309bd86bd521083d9c70f01f2de45fdc7c457` (`src/lib/presets/`).
