# Texture licences

These textures come from the [ez-tree](https://github.com/dgreenheck/ez-tree)
demo app and cover the built-in tree presets. `tools/textures/convert.sh`
converts them to KTX2, a file format for compressed GPU textures. The source
licences below apply to these converted files.
